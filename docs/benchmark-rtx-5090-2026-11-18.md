## Observations & Methodological Notes

- **Alibaba models vs MiniMax-H3 on 32 GiB VRAM**:
  - `vLLM-Omni` leads both Alibaba workloads (`qwen21_t2i` at `2.45s`, `wan22_i2v_14b` at `75.58s`) using `--quantization fp8` (and `--enable-cpu-offload` for Wan 2.2 MoE).
  - `ComfyUI` leads both MiniMax-H3 workloads (`3.83s` T2I, `48.34s` I2V) by keeping quantized `INT8 ConvRot` / `FP8 scaled` weights against ~31 GB of the 32 GiB VRAM budget, followed by `openfal` (`12.30s` T2I / `90.30s` I2V at `14.8–17.1 GB` peak VRAM using Counter/Pantry host streaming).
  - `vLLM-Omni` loads dequantized `BF16` weights for MiniMax-H3 (`40.23 GB` DiT + `51.51 GB` `Qwen3VL-32B` text encoder) and streams layers from disk/host via `DistributedLayerwiseOffloadBackend` (`checkpoint_mmap`, `--dlo-resident-layers 12`, `--enforce-eager`, `CUDNN_ATTN`), which limits peak VRAM to `14.2–16.3 GB` but makes PCIe host-to-device block streaming the dominant bottleneck (especially on the 6-step T2I run).
- **`minimax_h3_i2v` frame count constraint**: `openfal` and `ComfyUI` generate `73` frames (`3.04s` at `24 fps`). Because `vLLM-Omni` rejects video durations under `4s`, [bench_runner.py](../benchmark/bench_runner.py) passes `num_frames=97` for `minimax_h3_i2v`, which `vLLM-Omni` decodes as `107` frames (`4.46s` at `24 fps`) plus `32 kHz` stereo AAC audio.
- **`minimax_h3_t2i` native resolution**: Passing `extra_params={"min_generation_area": 1024}` ensures `vLLM-Omni` renders directly at `1344x768` instead of upscaling to its default `2048²` generation canvas (`2720x1536`).
- **Partition eviction fix in `openfal`**: The initial combined `openfal` sweep ([070636.json](../benchmark/results/bench_NVIDIA_GeForce_RTX_5090_20261118_070636.json)) hit a connection drop on the final `minimax_h3_i2v` partition transition (`qwen21` -> `H3-Image` -> `wan22` -> `FL2VA`). Adding `gc.collect()` during MiniMax pipe eviction in [minimax_h3_runner.py](../openfal/runtime/minimax_h3_runner.py) resolved cleanup ordering, and the clean isolated `minimax_h3_i2v` run is recorded in [072017.json](../benchmark/results/bench_NVIDIA_GeForce_RTX_5090_20261118_072017.json).
